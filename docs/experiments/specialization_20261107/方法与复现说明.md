# 方法与复现说明

本轮训练的是公开 OmniArch 的一维解码器及时间条件网络，编码器/Transformer 不更新。按几何分别训练适配器，不能据此宣称一个新解码器自动识别任意几何。TimeCondition 为 1→32→1024，输入 log(Δτ/0.01)，最后一层初始为零。

普通组使用物理速度；特化组以 U*=Ga²/μ 归一化，模型输出再还原单位。两组都保留原模型的历史均值/方差归一化。数据损失为平均 ((预测−真值)/U_b)²（特化组使用同单位的 U_b/U*）；物理组另加 λ×平均残差²，λ=10⁻⁴，200 步线性升权。残差是 (下一帧−末帧)/Δτ−L((下一帧+末帧)/2)−1。圆管另加三点单边轴心导数的平方；槽道不强制对称，因为训练和测试允许非对称初始扰动。每一步的壁面值强制为零，不对内部速度剖面投影为解析形状。

训练为单步监督、验证/测试为20步自回归；步数固定600，batch=32，AdamW初始学习率3×10⁻⁴，余弦降至初值的10%，梯度范数上限1。候选检查点为0、200、400、600步，按12条完整验证轨迹的平均20步误差选择。每种几何256条训练轨迹各构造10/15帧两个窗口；同一轨迹的窗口仅出现在同一训练集合。

所有轨迹采用常压力梯度的充分发展层流解析扰动：圆管使用 J0 的径向特征函数，槽道使用 sin(kπ(y+1)/2)。训练扰动前4个模态幅值范围为±[0.5,0.25,0.15,0.08]倍稳态平均速度；复合外推用6个模态、幅值±[0.8,0.35,0.2,0.12,0.07,0.04]，同时改变时间间隔。这是复合分布改变，不能由该组单独解释每种外推因素。随机时间原点为τ∈[0,0.03]；物理半尺度2.5–7.5 mm、ν=0.8–2×10⁻⁶ m²/s、U_b=0.005–0.03 m/s，密度1000 kg/m³。具体生成值全部存于 cases.json。

原 metrics.json 的 channel symmetry_or_axis_gradient 是预测剖面的不对称程度；对于非对称真值不应解读为预测误差。audited_metrics.csv 增加了相对真值的 reflection_prediction_error_over_Ub 字段，主要质量比较只使用真值误差、壁面值和动量残差。

固定主干的训练特征先缓存，训练耗时加上了单独报告的特征准备耗时；CNN不计算OmniArch特征。计时函数外部同步GPU；CNN虽与OmniArch同进程测试，但前向不调用OmniArch。本轮统一采用最后token解码的前向，单步与发布代码在浮点舍入范围内一致，长时序可能因数值路径产生差异，故所有组重新配对测量，不能与第一轮BF16耗时直接比较。

复现环境沿用父目录的 Python 3.10.20、PyTorch 2.6.0+cu118、NumPy 2.2.6、SciPy 1.15.3、psutil。在本目录依次运行：

```powershell
python specialize.py train
python specialize.py evaluate
python summarize.py
```

基座权重仍位于 ../weights/omniarch-base.pt。checkpoints/ 保存18个独立的最优检查点，包含适配参数和训练元数据；不包含3.08亿参数主干副本。完整预训练成本没有计入本次适配成本。
