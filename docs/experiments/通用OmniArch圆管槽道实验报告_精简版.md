# 通用 OmniArch 圆管与槽道实验报告

实验日期：2026 年 11 月 7 日。**本次测试未发现公开通用版 OmniArch 相对于有限差分法的精度或效率优势。**以下按六个步骤记录主要过程与结果，完整数据保留在[原始完整报告](通用OmniArch圆管槽道实验报告.md)中。

## 1. 统一工况

研究不可压缩、常物性、壁面无滑移的圆管和平行板槽道层流，以已知解析解为真值。稳态无量纲速度分别为 $2(1-y^2)$ 和 $\frac32(1-y^2)$，其中圆管 $y=r/R$，槽道 $y=Y/\delta$。

设置四组尺寸、黏度和驱动参数，网格点数取 64、128、256。代表工况为：密度 1000 kg/m³、动力黏度 0.001 Pa·s、半径或半间距 5 mm、稳态平均速度 0.01 m/s；对应圆管和槽道压力梯度分别为 3.2、1.2 Pa/m。

公开模型需要历史流场，因此设置两类测试：**已知稳态历史的保持测试**，以及同一压力驱动下、具有解析解的**衰减扰动预测**。均给定前 10 帧，预测后续 20 帧；无量纲时间步为 0.01。未来帧仅用于评价，具体工况与扰动定义见[实验配置](../../protocol.json)和完整报告。

## 2. 建立数值基准

稳态采用二阶中心差分和三对角直接求解；瞬态采用中心差分与 Crank–Nicolson 时间推进，并复用每次预测的矩阵分解。另设“复制最后一帧”基线。

解析解检查和加密验证均通过。由于稳态解为二次抛物线，差分节点误差接近浮点精度；网格间插值及瞬态加密呈约二阶收敛。N=128 时，稳态直接求解的相对误差约为圆管 $1.30\times10^{-14}$、槽道 $2.17\times10^{-15}$。

## 3. 开展 OmniArch 实验

使用公开 **base v0.4** 权重，检查点为 72,000 步、约 3.08 亿参数，代码固定于提交 `5fba14f`。该仓库是预览实现，不能直接等同于原论文模型。[仓库说明](https://github.com/Tarpelite/omniarch_pt/blob/5fba14f1ce93ec26d5c2b75b74ef17bf6c60dc02/README.md)

通过一维单场接口输入轴向速度，未微调、未作相似特化，也未修正预测壁面值。GPU 使用默认 bfloat16 混合精度，共完成 48 个测试记录；另在 CPU 上完成 4 个 FP32 复核记录。

## 4. 比较求解精度

采用覆盖全部预测帧的相对 L2 误差：圆管按径向面积加权，槽道按横向积分加权，并检查最大误差和边界条件。代表工况 N=128 的扰动预测结果如下；GPU 结果取四工况批次中的代表样本。

| 几何 | OmniArch GPU | 有限差分 FP64 | 复制末帧 |
| --- | ---: | ---: | ---: |
| 圆管 | 21.54% | 0.000712% | 4.13% |
| 平行板槽道 | 4.06% | 0.000665% | 3.96% |

稳态保持误差分别为 **14.43% 和 20.28%**，预测中出现非零壁面速度。CPU FP32 复核仍明显劣于有限差分；其中槽道扰动预测略优于复制末帧，但未改变主要结论。

## 5. 比较计算效率

硬件为 i9-12900H、RTX 3070 Laptop GPU（8 GiB）；PyTorch 2.6.0、SciPy 1.15.3。各项预热 2 次、测量 7 组。以下为 N=128、四工况各预测 20 帧的**总耗时中位数**；有限差分在 CPU 连续求解四次，OmniArch 在 GPU 一次批量预测。

| 几何 | 有限差分 FP64 | OmniArch GPU |
| --- | ---: | ---: |
| 圆管 | 0.648 ms | 861.517 ms |
| 平行板槽道 | 0.592 ms | 1009.448 ms |

计时包含数值方法的矩阵构造、分解与推进，以及模型的数据传输和推理；不含模型加载、历史生成及文件写入。同 CPU 复核也未发现模型耗时优势。GPU 单例推理峰值分配约 1613 MiB；有限差分独立进程峰值工作集约 68 MiB，两者计量口径不同。本次未训练，新增训练成本为零，原预训练成本未实测。

## 6. 分析实验结果

同设备、同输入配置下的重复推理输出一致，耗时存在波动。当前模型在所测问题上误差更大、运行更慢；因未达到有限差分的精度水平，不能报告“等精度加速比”。

**结论仅适用于本次未适配的一维速度输入方式。**传统方法显式使用方程和边界条件，模型仅读取历史场；稳态保持测试不能证明它能直接从参数求解稳态问题。四个物理工况共享归一化剖面，也不能作为独立的跨物理规律泛化证据。本报告可作为后续特化实验的基线，特化效果仍需另行验证。
