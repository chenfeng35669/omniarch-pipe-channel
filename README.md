# OmniArch 圆管与平行板槽道速度预测

我们关心的是，给模型看一段圆管或槽道的流动，它能否算准接下来速度会怎样变化。最初的通用 OmniArch 连已经稳定的速度剖面也会算出变化。普通微调缓解了这个问题，但连续预测时，小扰动的误差仍会积累。后续实验围绕两个问题展开：怎样学准每一步的速度变化，以及训练数据有没有覆盖这些变化。

**在 A 组原四模态测试上，连续预测 20 帧的整场速度误差为圆管 0.0000056%、槽道 0.0000079%。** 同批 128 节点有限差分分别为 0.000694% 和 0.000718%。对原测试中的同一批 48 条槽道轨迹，加入未见的第 7、8 阶扰动时，A 的扰动误差为 **1.541%**。在 A 的预测流程中接入物理后训练层后，误差降至 **0.004203%**。

## 1. 方程与误差指标

### 1.1 动量方程与稳态解

这两种流动都有解析解，适合检验模型从哪一步开始算偏。实验采用恒定压差驱动的充分发展层流，流体不可压缩、物性恒定，壁面无滑移。$u$ 为轴向速度，$G=-\mathrm{d}p/\mathrm{d}x>0$ 为单位长度压降，$\rho$ 为密度，$\mu$ 为动力黏度，$\nu=\mu/\rho$。

**圆管**的半径为 $R$，管壁无滑移，轴心处速度梯度为零。轴向动量方程与稳态解为

$$
\begin{aligned}
\frac{\partial u}{\partial t}
&= \frac{G}{\rho}
 + \frac{\nu}{r}\frac{\partial}{\partial r}
  \left(r\frac{\partial u}{\partial r}\right),\\[4pt]
u_{\mathrm{s}}(r) &= \frac{G}{4\mu}\left(R^2-r^2\right).
\end{aligned}
$$

**平行板槽道**的半间距为 $\delta$，两侧壁面位于 $y=\pm\delta$。相同压降下，轴向动量方程与稳态解为

$$
\begin{aligned}
\frac{\partial u}{\partial t}
&= \frac{G}{\rho} + \nu\frac{\partial^2 u}{\partial y^2},\\[4pt]
u_{\mathrm{s}}(y) &= \frac{G}{2\mu}\left(\delta^2-y^2\right).
\end{aligned}
$$

### 1.2 衰减扰动的解析解

稳态测试检查模型能否维持同一抛物线剖面。瞬态测试在稳态上叠加衰减扰动。记 $s$ 为无量纲空间坐标，$a$ 为圆管半径或板间半距，$\tau=\nu t/a^2$，$U_b$ 为稳态截面平均速度。瞬态解析解为

$$
u(s,\tau)=u_{\mathrm{s}}(s)
 + U_b\sum_{k=1}^{K} A_k\,\phi_k(s)\,e^{-\lambda_k^2\tau}.
$$

每一项代表一种衰减扰动，其空间函数 $\phi_k$ 在圆管中为贝塞尔函数，在槽道中为三角函数。解析解用于生成训练轨迹和检验预测。

### 1.3 整场误差与扰动误差

模型读取 **10 帧真实速度，随后使用自己的预测连续推进 20 帧**。由于稳态速度占了大部分，即使整条曲线看起来很接近，也可能把其中的小扰动算错。因此，在整场误差 $E_u$ 之外，我们还用真实扰动 $v=u-u_{\mathrm{s}}$ 的大小作分母，单独计算扰动误差 $E_v$。

$$
\begin{aligned}
E_u &= 100\%\,\frac{\lVert\hat u-u\rVert_w}{\lVert u\rVert_w},\\[4pt]
E_v &= 100\%\,\frac{\lVert\hat u-u\rVert_w}{\lVert v\rVert_w}.
\end{aligned}
$$

范数汇总一条轨迹的 20 帧与全部空间节点。圆管按截面面积加权，槽道按横向距离积分，再对测试轨迹等权平均。纯稳态只报告整场误差。**以下表内误差单位均为 %，越小越好。**

## 2. 通用 Base 基线

### 2.1 测试工况与网格

先看未经微调的 Base 能否做到两件事：给它已经稳定的流场，它能否保持原状；给它正在衰减的扰动，它能否跟上变化。我们将一维历史速度直接输入公开 Base v0.4，在标准、小尺寸、高黏度、大尺寸四组参数和三种网格上测试，两种几何共 48 条记录。四组参数的归一化剖面相同，同一网格下的误差保留四位小数后一致。

### 2.2 稳态漂移与扰动误差

| 网格节点数 | 圆管稳态保持 | 圆管衰减扰动预测 | 槽道稳态保持 | 槽道衰减扰动预测 |
|---:|---:|---:|---:|---:|
| 64 | 12.80% | 63.22% | 21.50% | 4.62% |
| 128 | 14.43% | 21.54% | 20.28% | 4.06% |
| 256 | 14.69% | 38.22% | 19.09% | 4.56% |

两类测试都按整场速度评分。在标准工况、128 个节点上，即使输入的是稳态，圆管和槽道的误差仍有 **14.43% 和 20.28%**。预测衰减扰动时，简单地复制末帧，误差也只有 **4.13% 和 3.96%**；同网格有限差分分别为 **0.000712% 和 0.000665%**。这说明仅给通用模型输入历史速度，还不足以算准这两种流动。[原始基线与物理参数](docs/experiments/通用OmniArch圆管槽道实验报告.md)

## 3. 普通微调与物理特化

### 3.1 按几何分别微调

通用 Base 在固定工况上连稳态也维持不住。我们给圆管和槽道各准备 256 条训练轨迹，让模型学习从历史速度预测下一帧。训练时冻结编码器和 Transformer，只更新各自的一维解码器和时间步适配器，约 83 万个参数；用另 12 条验证轨迹的 20 步预测误差选模型。

### 3.2 速度归一化与壁面约束

管道尺寸、压差或黏度一变，即使速度剖面的形状相似，速度数值也会不同；通用模型还曾在静止壁面预测出非零速度。因此，我们用速度尺度 $U_* = Ga^2/\mu$ 归一化输入，在训练中加入动量方程和圆管轴心对称条件，并在预测后将壁面速度置零。

### 3.3 特化改善圆管外推

本轮统一用 128 节点和 FP32 推理，通用 Base 也在同一批随机轨迹上重新评分。每种几何留出 16 条同分布轨迹和 8 条外推轨迹。

| 类别 | 方法 | 圆管同分布 | 槽道同分布 |
|---|---|---:|---:|
| OmniArch | 通用 Base | 15.844% | 5.323% |
| OmniArch | 普通微调 | 0.769% | 2.110% |
| OmniArch | 相似与物理特化 | 0.771% | 1.906% |
| 时间基线 | 复制末帧 | 2.130% | 4.169% |
| 数值方法 | 有限差分 | 0.000529% | 0.000636% |

从表中可以看出，第一次明显改善来自普通微调。再加物理特化，对槽道同分布有帮助，对圆管同分布几乎没有影响。换到外推轨迹时，圆管误差从 **3.244%** 降至 **2.852%**，槽道却从 **2.618%** 升至 **3.030%**。因此，我们进一步检查微调后的模型究竟把哪一部分算偏了。[微调与物理特化实验](docs/experiments/specialization_20261107/OmniArch相似物理特化实验报告.md)

## 4. 误差来源

### 4.1 模型层面的误差

#### 4.1.1 稳态背景掩盖单步变化

速度剖面的大部分是稳定的抛物线，真正随时间变化的扰动只占一小部分。因此，模型即使把整条曲线画得很接近，也可能算错相邻两帧的速度变化。单独对第一步的变化量评分，微调模型的相对误差在圆管上为 **37.6%**，在槽道上为 **30.8%**。

#### 4.1.2 连续反馈放大预测偏差

我们让同一个模型分别使用真实历史和自己的预测。到第 20 步，每步都给真实历史时，圆管和槽道的单帧误差为 **0.045% 和 0.145%**；连续用自己的输出时，分别升至 **1.362% 和 3.360%**。前一步的偏差会成为下一步输入的一部分。[滚动误差诊断](docs/experiments/圆管与槽道_后训练误差来源与改进实验.md)

#### 4.1.3 部分预测高估扰动能量

在这两个恒定驱动的算例中，流动应逐渐回到稳态。模型有时会反向预测，让速度偏离稳态的幅度变大。独立测试中，对普通微调模型逐步检查，圆管 **21.7%**、槽道 **24.5%** 的预测步触发了扰动能量上界。[能量上界对照](docs/experiments/圆管与槽道_后训练误差来源与改进实验.md)

### 4.2 数据层面的误差

#### 4.2.1 早期快速变化采样不足

高阶扰动衰减得快，取样稍晚，就很难看清它最初怎样变化。在早期后训练实验中，训练窗口内的单步速度变化中位数为圆管 **0.101%**、槽道 **0.217%**；测试轨迹刚开始预测时，分别为 **0.264%** 和 **0.419%**。测试开头需要预测的变化，比训练窗口中常见的变化更大。[训练窗口与测试轨迹对照](docs/experiments/圆管与槽道_后训练误差来源与改进实验.md)

#### 4.2.2 训练集只含前四阶扰动

原训练集只包含前四种空间扰动形状。对同一批槽道轨迹保留前四阶和原时间步，仅叠加第 5、6 阶，第一阶段纠偏模型的整场误差便从 **0.000593%** 升到 **0.0385%**。即使步长熟悉，换一种扰动形状也会影响预测。[单因素配对测试](docs/experiments/圆管与槽道_三帧外推逐步纠偏与稳态对照.md)

#### 4.2.3 训练时间步覆盖不足

原训练数据只用了 0.005、0.01 和 0.02 三种无量纲时间步。保持圆管轨迹的物性和初始扰动相同，单独改变时间步，第一阶段纠偏模型的整场误差从 **0.000120%** 升至 **0.4953%**。这项对照说明，除了增加扰动形状，还需要覆盖不同时间间隔下的速度变化。[时间步配对测试](docs/experiments/圆管与槽道_三帧外推逐步纠偏与稳态对照.md)

## 5. 模型与数据优化

以下各小节与第 4 章逐项对应。例如，4.1.2 检验了连续反馈怎样放大偏差，5.1.2 说明怎样在反馈之前修正速度。

### 5.1 模型层面的优化

#### 5.1.1 扣除稳态并学习速度变化

为看清 4.1.1 中被稳态背景掩盖的变化，我们先用已知工况计算稳态剖面，从历史速度中扣除它，单独学习扰动。在原 16 条同分布轨迹上，扣稳态后逐节点预测，圆管和槽道的整场误差为 **0.444% 和 0.646%**；把扰动分解为空间模态，再预测各模态幅度每步改变多少，误差降至 **0.0658% 和 0.0850%**。据此，后续网格模型也把学习目标转向了相邻帧的速度变化量。[稳态与扰动模态实验](docs/experiments/圆管与槽道_稳态扰动模态预测实验报告.md)

#### 5.1.2 修正每一步预测后再反馈

针对 4.1.2 的误差累积，先用最近三帧的两次速度增量 $d_n=u_n-u_{n-1}$ 和 $d_{n-1}$，按加权最小二乘估计衰减系数 $\gamma$。每条轨迹只估计一次，取值在 0 到 1 之间。三帧外推给出初值 $\tilde u_{n+1}$，纠偏层学习它与真实下一帧之间的差值 $c_n^*$。

$$
\begin{aligned}
\tilde u_{n+1} &= u_n+\gamma d_n,\\
c_n^* &= u_{n+1}-\tilde u_{n+1},\\
\hat u_{n+1} &= \tilde u_{n+1}+\hat c_n .
\end{aligned}
$$

速度增量支路先修正三帧外推，OmniArch 再用最近 **10 帧**的特征修正剩余偏差。将纠正后的速度放回历史窗口，再预测下一步。下表在同一批 72 条同分布轨迹上比较各方法，最后一项组合还采用了 5.1.3 的能量上界。

| 类别 | 方法 | 圆管 | 平行板槽道 |
|---|---|---:|---:|
| OmniArch | 普通微调后直接预测 | 0.8803% | 2.1985% |
| 时间基线 | 最近三帧直接外推 | 0.2242% | 0.9745% |
| 时间对照 | 仅训练速度增量纠偏 | 0.000350% | 0.000848% |
| 组合方案 | 增量纠偏加 OmniArch 修正 | 0.000135% | 0.000719% |
| 组合方案 | 再扣稳态并限制扰动能量 | 0.000139% | 0.000458% |
| 数值方法 | 有限差分 | 0.000646% | 0.000762% |

#### 5.1.3 限制每一步的扰动能量

针对 4.1.3 中扰动被算大的情况，我们试过在训练损失中加入强形式动量、弱形式动量、弱形式加能量收支三种约束。在 32 条同分布轨迹上，圆管从 **0.828%** 分别变为 **0.905%、0.869%、0.889%**，槽道从 **1.764%** 分别变为 **1.746%、1.764%、1.753%**，速度误差没有稳定下降。[物理后训练对照](docs/experiments/圆管与槽道_强弱形式及能量平衡后训练对比.md)

随后改在每次预测后直接检查扰动 $v_n=u_n-u_{\mathrm{s}}$。若扰动能量超过上一帧，就保留其方向并缩小幅值，使其满足

$$
\frac12\lVert v_{n+1}\rVert_w^2
\leq \frac12\lVert v_n\rVert_w^2 .
$$

在当时的圆管外推轨迹上，联合纠偏的整场误差为 **1.7872%**，扣稳态后降至 **0.3205%**，再限制能量降至 **0.0882%**。此时扰动本身的误差仍有 **5.70%**，所以还需补足训练数据。[三帧纠偏与扰动精度补测](docs/experiments/圆管与槽道_三帧外推逐步纠偏与稳态对照.md)

### 5.2 数据层面的优化

#### 5.2.1 补采扰动刚出现的几帧

针对 4.2.1，把一半新增轨迹的起始时刻放在无量纲时间 0 至 0.001，并把第 1、2、4 个更新位置的增量用于训练时间支路。这样，模型能在快速扰动仍明显时看到它怎样衰减。第 6.1 节用等量的早期和较晚样本检验了这项改动。

#### 5.2.2 将训练扰动扩至前六阶

针对 4.2.2，每种几何保留原 256 条训练轨迹，再加入 **768 条六模态轨迹**，使第 5、6 阶形状也有训练样本。测试时用相同条件下的新轨迹检验六阶预测，再额外加入未训练的第 7、8 阶，检查方法的适用边界。

#### 5.2.3 将训练时间步从三种扩至八种

针对 4.2.3，在 **0.001–0.025** 内选取 8 个训练步长，为每个步长提供相邻帧的速度变化样本。推理时遇到两个训练节点之间的新步长，就用邻近节点的更新矩阵插值。第 6.2、6.3 节分别说明更新方法和独立测试结果。[数据扩充与最终方案](docs/experiments/圆管与槽道_三帧外推逐步纠偏与稳态对照.md)

## 6. 分步长更新与物理后训练

先补数据、按时间步学习更新，得到 A；再针对 A 在未见高阶扰动上的误差接入物理后训练层，得到 E。

### 6.1 补充早期扰动样本

为检验第 5.2.1 节的早期采样是否有效，我们固定训练轨迹与样本总数，只把三个较晚的采样位置移到扰动初期。单独测试时间支路时，圆管扰动误差从 **0.000207%** 降至 **0.000111%**，槽道从 **0.0000826%** 降至 **0.0000559%**。

### 6.2 按时间步学习更新

有了 8 个步长的训练数据后，我们在每个步长上分别学习速度增量怎样更新。推理步长落在两个训练节点之间时，用邻近四点的更新矩阵插值。每一步仍扣除稳态、用 OmniArch 修正剩余偏差，并限制扰动能量。

### 6.3 三组独立测试结果

训练集用于拟合模型参数，验证集用于选模型。选模时，在原训练条件和新增训练条件下各用 36 条验证轨迹，以同批有限差分误差为参照，对整场和扰动误差、两类条件等权评分。**下表三列都是测试集结果。** 模型定好后，每种几何另取三批未参与训练或选模的轨迹，按扰动形状和时间步分组。

- **四阶扰动组（72 条）**：只用前四阶扰动，时间步为 0.005、0.01 或 0.02。新旧版都用过这类条件，测试的是新轨迹。
- **六阶扰动·已学步长组（72 条）**：加入第 5、6 阶扰动并扩大扰动幅值范围，时间步取 0.0025 或 0.025。这些条件只在新版训练中出现过。
- **六阶扰动·未学步长组（60 条）**：仍使用前六阶扰动，时间步换为 0.00375、0.0125 或 0.0225。三个值都在新版训练步长的上下限之间，但训练时没有用过。

| 组合预测 | 新版 | **0.0000079%** | **0.0000100%** | **0.0000098%** |
| 数值方法 | 有限差分 | 0.000718% | 0.001112% | 0.001183% |

改进最大的是第二组，即六阶扰动配合新版学过的步长。以圆管为例，整场误差从 **0.0926%** 降到 **0.0000081%**。单独看小扰动，同一批轨迹上的圆管误差从 **5.526%** 降到 **0.000419%**，槽道从 **0.6543%** 降到 **0.000135%**。第 7 节进一步比较早期样本、分步长更新和 OmniArch 修正各自的贡献。

### 6.4 高阶扰动的后训练纠偏

**问题。** 在原测试中，保持同一批 48 条槽道轨迹的时间步、物性、起始时刻和前六阶扰动完全相同，只加入第 7、8 阶，A 的平均扰动误差就从 **0.0000554%** 升至 **1.541%**。这批轨迹使用已训练的步长 0.001 或 0.0025，暴露的是对新扰动形状的预测偏差。另一个外推问题来自过大步长：在先前独立复核中，槽道步长高于 0.025 时，新版、上轮方案的整场误差分别为 0.7192%、0.0122%，因此 A 在该区间沿用上轮方案。[原始工况与误差记录](docs/experiments/圆管与槽道_三帧外推逐步纠偏与稳态对照.md)

**改法。** 冻结 A，用方程求解器教一个额外的更新层预测扰动的下一步。每种几何用 256 个平滑的局部扰动，在 16 种时间步上用 24 个有限差分子步生成 4,096 对训练样本。推理时，若时间步超出 A 的训练范围 0.001–0.025，或首帧扰动在已学前六阶形状以外的部分超过其范数的 0.03%，就用新层推进；其他轨迹继续用 A。这一组合称为 **E**。触发时原网络的混合权重已由先前验证选为 0，因此收益来自新层的方程监督。模型和调用阈值均在本次原测试集回测前固定。

**槽道结果。** 在原来出现 1.541% 扰动误差的 48 条轨迹上，各方法使用同一网格和相同观测，比较连续预测 20 步的平均相对误差。

| 类别 | 方法 | 整场速度误差 | 扰动误差 |
|---|---|---:|---:|
| 组合预测 | 分步长纠偏 A（后训练前） | 0.3386% | 1.541% |
| 组合预测 | A 加物理后训练 E | **0.001021%** | **0.004203%** |
| 数值方法 | 有限差分 | 0.000762% | 0.003218% |

加入物理后训练后，48 条槽道轨迹的扰动误差全部下降，平均扰动误差相对降低 **99.73%**，仍略高于同网格有限差分。圆管结果及其他工况对照见第 7.4 节。

## 7. 消融实验

### 7.1 A–E 组对照设计

以分步长纠偏方案 A 为参照，B、C、D 分别检验采样、时间更新和网络修正；E 检验在 A 的推理流程上再加物理后训练能降低多少外推误差。

- **B 检验早期采样。** 将每条轨迹额外用于训练时间支路的三个位置，从第 1、2、4 个移到第 11、18、26 个，样本数相同。
- **C 检验分步长更新。** 保留早期样本，把 8 个时间步各自的更新矩阵换成一个共享的、随步长二次变化的公式。
- **D 检验 OmniArch 的额外贡献。** 直接使用 A 的时间支路权重，只将每步的网络残差输出置零。
- **E 检验物理后训练。** 保留 A，加入第 6.4 节的物理更新层，回到原来暴露高阶误差的 48 条轨迹上逐条比较。

B、C 均重新拟合时间支路与网络残差层。各组共用训练轨迹、壁面条件、稳态剖面和能量上界。A、B、C 各使用相同数量的训练样本（时间支路 13,312 个、网络支路 10,240 个），采用相同的样本加权、正则候选和双指标验证规则。

### 7.3 分步长更新贡献最大

**早期样本（B 对 A）。** 用等量较晚样本替代早期样本后，覆盖和中间步长的扰动误差分别变为 A 的 **1.72 倍、3.43 倍**（圆管）和 **1.81 倍、2.16 倍**（槽道）。三个种子的变化方向一致。

**时间更新方式（C 对 A）。** 对未训练的中间步长，换成全局公式后，圆管和槽道的整场误差都上升了两个数量级以上。对每条轨迹先取三个种子的均值，两类步长下 C 的整场和扰动误差均高于 A。这是三项改动中影响最大的一项。

**OmniArch 的额外贡献（D 对 A）。** 关闭残差后，圆管在覆盖和中间步长上的整场误差分别增加约 **11% 和 6%**。槽道在覆盖步长上几乎持平，关闭残差后的扰动误差还略低；中间步长上启用残差有小幅整场收益。

对 48 条轨迹配对重采样 10,000 次，B − A 和 C − A 在两种几何、两类步长上的整场与扰动误差差值，其 95% 区间均高于零。D − A 的圆管整场差值区间高于零，但四组扰动差值区间均跨零，网络对小扰动的额外收益仍缺少一致证据。

**复核。** 在上轮 72 条新增覆盖轨迹上，重建的 A 复现了已报告的误差；D 也通过独立递推复算。A–D 的上述比较限于测试的早期六模态轨迹。

## 快速复现

在仓库根目录运行。已验证环境为 Python 3.10、PyTorch 2.6.0 和 NVIDIA CUDA。以下为 CUDA 11.8 的安装示例。

```bash
python -m pip install torch==2.6.0 --index-url https://download.pytorch.org/whl/cu118
python -m pip install -r requirements.txt
python benchmark.py validate
```

从上游下载 **OmniArch Base v0.4、72,000 步**权重（约 1.23 GB），放到 `weights/omniarch-base.pt`，也可用环境变量 `OMNIARCH_CKPT` 指向已有文件。复现入口会核对权重 SHA-256。[Base 权重下载](https://bhpan.buaa.edu.cn/link/AA4C3D921A4EC6439B952F161E819F3938) · [上游代码与模型说明](https://github.com/Tarpelite/omniarch_pt/tree/5fba14f1ce93ec26d5c2b75b74ef17bf6c60dc02)

```bash
python specialization_20261107/specialize.py train-plain
python reproduce.py
```

第一条命令生成解析训练轨迹并训练圆管、槽道各三个适配器。第二条首次运行时重建 A 的纠偏权重，分别输出 A、E、有限差分的整场误差、扰动误差及新层触发数。只看槽道可运行 `python reproduce.py --geometry channel`。运行 `python run_ae.py` 可在两种几何的 A 权重都生成后复核其余七类工况。

## 代码入口

- [benchmark.py](benchmark.py) — 解析速度、稳态求解、有限差分和通用模型基线。
- [specialize.py](specialization_20261107/specialize.py) — 轨迹生成、普通微调与物理特化。
- [base_pipeline.py](base_pipeline.py) — A 的稳态处理、分步长纠偏和预测。
- [integrated.py](integrated.py) — E 的物理后训练及按轨迹选择更新方式的入口。
- [reproduce.py](reproduce.py) — 原 48 条轨迹的 A/E 对照与结果表。
- [ablation.py](ablation.py) — 训练适配器后运行 `python ablation.py`，对照完整 A、等量晚期样本 B、共享时间公式 C、关闭网络残差 D。

四组消融中，两种几何在未训练的中间步长上改用共享时间公式后，整场误差都增大了两个数量级以上。关闭 OmniArch 修正后，圆管的增幅约为 6%。这组对照可用来区分分步长更新与网络修正各自的贡献。

原始基线可分别用 `python benchmark.py baseline`（有限差分与复制末帧）和 `python benchmark.py model --device cuda`（通用 Base）运行。

仓库内使用的上游推理源码及其 [MIT 许可证](vendor/omniarch_pt/LICENSE) 位于 `vendor/omniarch_pt/`。训练数据可以由脚本生成。
